# 追上去！· 追及问题实验室

面向**六年级**的追及问题互动原型：小明先跑 30 米、每秒 4 米，小红每秒 6 米，几秒追上？

游戏不直接给公式，而是让学生**先猜 → 调速度做实验 → 拖时间轴复盘 → 换视角发现"速度差" → 两个 90 验算**。

---

## 一、怎么打开

### 1. 电脑上（最简单）
双击 `index.html` 即可，Chrome / Edge / Safari 都行。
首次打开需要联网（从 CDN 加载 3D 引擎和角色模型，约 1 MB）。

### 2. 平板上（课堂用）
平板不能直接打开本地文件，需要让电脑当服务器：

```bash
cd chase-lab
./serve.sh
```

脚本会打印一个 `http://192.168.x.x:8080` 的地址。
**电脑和平板连同一个 Wi-Fi**，在平板浏览器里输入这个地址，横屏即可。
（iOS 建议"添加到主屏幕"，全屏更像一个 App。）

## 二、一节课怎么用（约 20 分钟）

| 环节 | 学生做什么 | 老师做什么 |
|---|---|---|
| 猜一猜 | 从 3 / 5 / 7.5 / 15 秒里选一个 | **先不评价**，把全班的选择记在黑板上 |
| 做实验 | 拖动速度，看小红能不能追上 | 只问："你看到了什么？"不急着纠正 |
| 见证错误 | 如果猜了 5 秒，会自动回到第 5 秒看现场 | 追问："为什么 5 秒时还差 20 米？" |
| 换视角 | 点"坐上小明的肩膀"，看小红每秒只靠近 2 米 | 追问："小明看起来不动，为什么还是 15 秒？" |
| 看证明 | 两个 90 对齐的那一刻 | 板书：追及时间 = 路程差 ÷ 速度差 |
| 彩蛋 | 想 10 秒追上，要几米/秒？ | 留给学有余力的孩子 |

关键设计：**从头到尾没有直接给出"30 ÷ (6−4)"**，这个式子是在第 15 秒、两个 90 对齐之后才浮现的。

**已实现**

## 四、技术说明

- **引擎**：Three.js r160（CDN，ESM + importmap）
- **角色**：`RobotExpressive.glb`（three.js 官方示例模型，CC0），同一模型两套配色
- **动作**：模型自带 Idle / Running / ThumbsUp 等
- **场景**：程序化生成（几何体 + Canvas 贴图），跑道的每米刻度、10 米线、终点棋盘格都是脚本画的
- **为什么不用物理引擎**：位置就是 `x = x₀ + v·t`，精确、可倒放、数字和数学完全一致
- **为什么镜头不变焦**：保证"1 米 = 固定像素"，不然差距缩小的速度会被视觉扭曲

### 想改数字？
打开 `index.html` 搜索 `const CFG`：

```js
const CFG = {
  vMing: 4,       // 小明速度
  startX: 30,     // 小明先跑 30 米
  finishX: 100,   // 公交站位置
  segM: 2,        // 追赶绳每格 2 米
  official: 6,    // 题目里小红的速度
  minV: 3, maxV: 8,
};
```

> 注意：改完 `segCount`（= 先跑距离 ÷ 每格米数）也要跟着改，页面上的追赶绳格子数量是自动生成的，但文案里的"15 格"是写死的。

### 源码结构
```
src/style.css    样式
src/body.html    页面结构
src/game.js      全部逻辑（3D / 模拟 / 流程）
build.sh         合成单文件 index.html
```
改完源码跑 `./build.sh` 重新生成。

## 五、已知限制

- 第一次打开必须联网（CDN）。断网教室需要离线版。
- 角色是机器人，不是小朋友。原型可以，正式课建议换真人模型。
- 只做了追及问题的"同向追赶"，相遇问题还没做。
- 没有存档，刷新即重来。
